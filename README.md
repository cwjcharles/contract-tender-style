# contract-tender-style

甲方视角的合同与招标文件写作风格技能。根据已有业务要点起草正式条款，或润色合同、招标文件、招标公告、资格预审文件、询价文件和用户需求书。

| 项目 | 信息 |
|---|---|
| 版本 | v1.1.0 |
| 更新日期 | 2026-10-29 |
| 通用规则模块 | LAT v2.0 |

## 适用方式

- **提纲起草**：按已有提纲、章节安排和业务要点写成正式条款，缺失事实使用占位符。
- **成稿润色**：统一称谓、术语、句式、编号、标点和交叉引用，保留原文实质安排。
- **强化甲方表达**：把原文已有权利和履行条件表达清楚；涉及新增商业安排时列为待确认事项。

本技能以清晰、克制、可执行的甲方法律文书表达为目标。金额、期限、付款、验收、违约、解除、风险分配及知识产权安排均受事实边界约束；不自行编造或扩大实质权利义务。

## 使用示例

起草：

```text
按 contract-tender-style，根据下列业务要点起草交付条款。
缺失金额、日期和地点用占位符，不补造付款条件或违约责任。
【业务要点】……
```

润色：

```text
按 contract-tender-style 润色下列条款，只改语言和表达。
保留金额、期限、权利义务及风险分配，未核实的交叉引用列为待确认。
【原条款】……
```

用户要求直接交付时，按输入状态输出起草稿、润色稿或含占位符的工作稿，并按需附待确认事项。技能负责文风和表达；法律风险识别及条款效力审查属于另行提出的任务。

## 内置去 AI 味规则

写作、改稿和交稿前读取 [references/less-ai-tone-rules.md](references/less-ai-tone-rules.md)。规则自带，不依赖另行安装其他技能。

- B/F 命中先复核，再作最小修改；H 人审、X 排除和停用项默认保留，不要求清零。
- 条款编号、法定清单、同类条款平行句式、定义及必要法律逻辑不被机械改写。
- 同义重命名规则不混同法律概念；衔接规则不破坏法律文书的必要逻辑；分号规则不破坏并列义务和对应关系。
- 专业禁用表达继续作为个人文风规则独立执行，不因上游撤销某项通用判据而失效。

## 安装

```powershell
git clone https://github.com/cwjcharles/contract-tender-style.git
```

将整个仓库目录放入所用 Agent 的 skills 目录，保留以下文件：

```text
contract-tender-style/
├── SKILL.md
├── README.md
└── references/
    └── less-ai-tone-rules.md
```

技能版本记录在 `SKILL.md` 的 `metadata.version`。通用规则的来源署名及 CC BY-NC 4.0 许可链接见规则文件顶部。
